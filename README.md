# Superstore Data Analysis

This project analyzes the Superstore dataset using Python and Pandas.
## Project Overview

The goal of this project is to analyze sales, profit, categories, sub-categories, discounts, and regional performance using the Superstore dataset.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- VS Code

## Key Insights

- Technology was the best-performing category in terms of sales and profit.
- The West region performed the best in terms of sales and profit.
- Tables, Bookcases, and Supplies were loss-making sub-categories.
- Higher discounts were generally associated with lower profit.
- The overall profit margin was 12.47%.

## Analysis Performed

- Analyzed total sales and total profit.
- Analyzed monthly and yearly sales trends.
- Compared sales and profit across categories.
- Identified profitable and loss-making sub-categories.
- Analyzed the impact of discounts on profit.
- Compared sales and profit across different regions.
- Analyzed category performance within each region.
- Calculated profit margins for sub-categories and regions.

## Conclusion

This analysis provides useful insights into the company's sales and profit performance. Technology was the strongest category, while the West region was the best-performing region. Some sub-categories, such as Tables and Bookcases, generated losses and may require further investigation.
