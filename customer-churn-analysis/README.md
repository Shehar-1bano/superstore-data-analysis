# Customer Churn Analysis

## Project Overview

This project analyzes customer churn patterns using Python and pandas. The goal is to identify customer groups with higher churn rates and compare churn behavior across contract type, internet service, technical support, monthly charges, and customer tenure.

## Tools Used

- Python
- Pandas
- Matplotlib
- GitHub

## Analysis Performed

- Dataset inspection and missing-value check
- Overall churn rate calculation
- Churn rate by contract type
- Churn rate by internet service
- Churn rate by technical support
- Average monthly charges by churn status
- Average customer tenure by churn status
- Business-focused insight generation

## Key Questions

1. What percentage of customers churn?
2. Which contract type has the highest churn rate?
3. Which internet service group has the highest churn rate?
4. Does technical support relate to churn differences?
5. How do monthly charges and tenure differ between churned and retained customers?

## How to Run

```bash
py churn_analysis.py
```

The script prints the analysis results and creates charts for the main categorical comparisons.
